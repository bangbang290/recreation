# 레트로 워크숍 수정판 8 — 그림 이어그리기 시계 효과음

## 적용
ZIP 압축을 풀고 app.py, index.html, requirements.txt, README.md 네 파일을 기존 GitHub 저장소에 덮어쓰세요. Streamlit 진입 파일은 app.py입니다.
이 버전의 유튜브 BGM은 Streamlit에서 실행하세요. index.html 더블클릭은 게임 미리보기만 지원하며, 로컬/임시 주소의 유튜브 재생은 제한될 수 있습니다.

## 진행 순서
1. Streamlit 게임 메인 화면 맨 위의 진행요원 창 열기 버튼을 누릅니다. 새 탭으로 열리면 탭을 별도 창으로 끌어내도 됩니다. 팝업이 차단되면 해당 사이트의 팝업을 허용합니다.
2. Windows+P → 확장. 메인 화면은 스크린, 진행요원 창은 노트북에 둡니다.
3. 진행요원 창 맨 위 유튜브 BGM에서 서커스 또는 겨울을 선택합니다.
4. 플레이어 연결 → 연결 완료 후 재생을 누릅니다. 자동재생이 차단되면 영상 안의 ▶를 직접 누릅니다.
5. 음량 슬라이더와 한 곡 반복을 조절합니다. 다른 음악은 링크를 붙여넣고 링크 저장 → 재생을 누르세요.
6. 음악퀴즈 및 보너스 안무 화면으로 이동하면 BGM이 자동 일시정지됩니다. 다른 게임으로 돌아온 뒤 재생을 눌러 재개합니다.

기본 링크: 서커스 https://www.youtube.com/watch?v=UyPNvJsr92g / 겨울 https://www.youtube.com/watch?v=-u13DgqNCt8
영상 링크를 지원합니다. 유튜브 라디오/재생목록만 지정한 링크는 지원하지 않습니다. 영상 링크에 재생목록이 붙어 있으면 해당 영상만 사용합니다.

## 소리와 창
- BGM은 진행요원 창에서만 재생합니다. 직원용 화면에 영상이나 점수가 나타나지 않습니다.
- 기존 합성 BGM 4곡은 제거했습니다. 그림 이어그리기는 사람 목소리 없이 시계 효과음과 짧은 벨을 사용합니다. 직원용 창에서 효과음 켜기를 한 번 누릅니다.
- 진행요원 창을 닫으면 BGM도 종료됩니다. 같은 PC의 Chrome/Edge에서 두 창을 유지하세요. 별도 로그인·권한 분리 기능은 아닙니다.
- 인터넷 연결이 필요합니다. 광고, 영상의 외부 재생 제한, 브라우저 자동재생 제한의 영향을 받을 수 있습니다. 유튜브 재생 오류 코드를 화면에 표시합니다.
- 외부 재생이 제한되면 다른 링크로 교체하거나 유튜브에서 열기를 이용할 수 있습니다. 별도 유튜브 창으로 재생할 경우 프로그램의 자동 일시정지는 적용되지 않으므로 직접 멈춰주세요.
- 설정·점수·링크는 백업 JSON에 포함됩니다. 행사 전후 백업을 다운로드하세요.

## 게임
음악퀴즈 + 보너스 안무 / 명대사 23개 / 초성 7개 카테고리(70+12개) / 일심동체 21개 / 그림 이어그리기(14+4개).
초성은 제시어 1~7 → 카테고리 공개 → 문제 시작 순서입니다.
그림은 종이와 펜으로 진행하며 기본 5초가 자동 반복됩니다. 마지막 주자 뒤 자동 카운트 정지를 누르세요.

## 확인 범위
기존 게임 회귀 테스트, 유튜브 URL 검증, 곡 선택, 음량, 음악퀴즈 자동 일시정지와 수동 재개, Streamlit 직원용·진행요원용 실행 테스트를 통과했습니다.
실제 유튜브 영상 재생 및 배포 환경의 두 창 동기화는 이 환경에서 검증하지 못했습니다. 행사 전 배포된 앱에서 두 링크의 재생과 게임 전환 시 일시정지를 확인해주세요.

수정판 5: iframe 안에서 주소를 추측해 팝업을 열던 코드를 제거하고 Streamlit의 직접 링크 버튼으로 변경했습니다. 메인·진행요원에 같은 연결 ID를 전달합니다. 연결 상태 문구와 최초 연결 재시도를 추가했습니다. 기존 창을 모두 닫고 메인 앱을 다시 열어 시작하세요.


## 수정판 7 — 슈퍼마리오 모션
- 로비 바닥에 빨간 M 모자·파란 멜빵바지의 픽셀 마리오를 배치했습니다. 세 가지 달리기 자세가 교대로 표시됩니다.
- 18초마다 달리기 → 물음표 블록 점프와 코인 획득 → 굼바 밟기와 튕겨 오르기 → 초록 파이프 넘기 → 깃발 내리기·반짝임을 반복합니다.
- 코인 회전, 블록 반동, 굼바 눌림, 구름 이동도 함께 재생됩니다. 모션의 100·200 숫자는 장식이며 실제 팀 점수와 무관합니다.
- 모션 끄기/켜기 버튼으로 조절합니다. 게임에 들어가면 모션은 숨겨지고 게임 선택 화면으로 돌아오면 다시 시작합니다. 운영체제의 동작 줄이기 설정에서는 정지된 장면으로 표시됩니다.
- 기존 화면 높이 맞춤과 5개 게임·진행요원 창·유튜브 BGM은 유지했습니다. 화면이 좁거나 낮을 때 캐릭터 크기도 줄어듭니다.
- 추가 이미지 파일이나 외부 애니메이션 라이브러리는 필요하지 않습니다.
- 압축을 푼 뒤 index.html을 더블클릭하면 모션을 미리 볼 수 있습니다. 행사 운영과 유튜브 BGM은 Streamlit 앱에서 실행하세요.

### 이번 수정의 확인 범위
기존 게임·타이머·정답 공개·점수·유튜브 제어 검사와 HTML/SVG 구조 검사를 통과했습니다. 브라우저 미리보기 새로고침이 이 환경의 접근 제한으로 차단되어, 새 모션의 브라우저 재생 및 배포된 전체화면 검증은 완료하지 못했습니다. 업로드 후 메인 화면에서 모션과 다섯 게임팩이 함께 보이는지 확인해주세요.

## 수정판 8 — 그림 이어그리기 시계 효과음
- 사람 목소리로 숫자를 읽는 기능을 제거했습니다. 화면의 5·4·3·2·1 숫자는 유지합니다.
- 카운트가 줄어들 때마다 시계의 째깍·째깍 소리가 번갈아 울립니다. 5초가 끝나면 짧은 벨이 울리고 다음 주자의 5초 카운트가 자동으로 시작됩니다.
- 일시정지·자동 카운트 정지·게임 전환·효과음 끄기는 시계 소리와 예약된 소리를 함께 멈춥니다.
- 슈퍼마리오 모션, 화면 맞춤, 기존 5개 게임과 유튜브 BGM 설정은 유지했습니다. 추가 음원 파일이나 다운로드는 필요하지 않습니다.
- 적용 후 기존 직원용·진행요원 창을 닫고 다시 여세요. 직원용 화면에서 효과음 켜기를 한 번 누른 뒤 그림 그리기를 시작합니다.
- 확인: 숫자별 1회 재생, 종료 벨, 5초 자동 반복, 일시정지·재개, 음소거, 게임 전환 시 정지, 진행요원 창 중복 재생 방지 검사를 통과했습니다. 실제 행사 스피커의 음량은 효과음 켜기 후 조절해주세요.
