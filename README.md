# 레트로 워크숍 수정판 14 — 그림 이어그리기 웹캠 추가

## 적용 방법

ZIP을 풀고 **app.py, index.html, requirements.txt, README.md** 네 파일을 기존 GitHub 저장소에 덮어쓰세요. Streamlit 실행 파일은 app.py입니다.
적용이 끝나면 기존 직원용 화면과 진행요원 창을 모두 닫고 다시 여세요. 이전 버전 창을 함께 열어두지 마세요.

## 수정판 14: 그림 이어그리기 웹캠

1. USB 웹캠을 직원용 화면을 띄우는 PC에 연결하고 Windows 카메라 앱을 닫습니다.
2. 그림 이어그리기를 선택하면 **왼쪽은 제시어·현재 주자·남은 시간**, **오른쪽은 웹캠**으로 표시됩니다.
3. 오른쪽 **카메라 켜기**를 누르고 카메라 권한을 허용합니다. 종이가 잘 보이도록 웹캠을 맞추세요. 장치 선택·180° 회전·좌우 반전도 가능합니다.
4. **4명 그리기 시작**을 누르면 기존처럼 한 사람당 5초씩 진행합니다. 주자 전환이나 일시정지 때문에 카메라가 끊기지 않습니다.
5. 4번 주자가 끝나면 타이머만 종료됩니다. 웹캠은 유지되어 완성된 그림을 다 같이 볼 수 있습니다. 다음 그림 문제로 넘어가도 영상은 이어집니다.
6. 카메라의 **끄기**를 누르거나 다른 게임으로 이동하면 웹캠 연결이 종료됩니다. 카메라 끄기는 그리기 타이머를 중단하지 않습니다.

카메라는 자동으로 켜지지 않으며 직원용 화면에서 켜야 합니다. 진행요원 창에서는 별도 카메라를 실행하지 않습니다. 카메라 사용 중에도 제시어는 공개 버튼을 누르기 전까지 숨겨집니다.

## 수정판 13에서 반영한 내용

- 게임 순서: **초성 → 음악퀴즈 → 일심동체 → 명대사 → 그림 이어그리기**.
- 그림 이어그리기 대기 화면의 첫 주자·마지막 주자 안내 문구를 삭제했습니다. 4명 × 기본 5초, 째깍 소리와 종료 벨은 유지합니다.
- 보너스 안무를 메뉴와 진행 기능에서 제거했습니다.
- 이름 명단을 7개 분임에 자동 배정하고, 팀명·구호·명단을 수정·저장할 수 있습니다.
- 점수 입력·계산·점수판을 제거했습니다. 수기 집계한 최종 우승팀을 진행요원이 직접 선택해 발표합니다.
- 초성은 정답 버튼 한 번으로 정답 공개 후 자동으로 다음 문제로 넘어갑니다.
- 일심동체는 제시어 옆에 USB 웹캠을 표시할 공간과 연결 버튼을 추가했습니다.

## 1. 분임 배정과 팀명·구호

1. 진행요원 창 상단에서 **01 · 7분임 편성 / 팀명 / 구호**를 펼칩니다.
2. 참가자 이름을 한 줄에 한 명씩 붙여넣습니다. 쉼표로 구분해도 됩니다. 동명이인은 부서 등을 붙여 구분하세요.
3. **7분임 자동 배정**을 누릅니다. 명단을 무작위로 섞어 분임별 인원 차이가 최대 1명이 되도록 배정합니다.
4. 분임별 팀명과 구호를 입력하고 **팀명·구호·명단 저장**을 누릅니다. 아래 팀원 명단을 직접 옮겨 적어 조정을 할 수도 있습니다.
5. **직원 화면에 분임 소개**를 누르면 TV 화면에 7개 분임의 팀명·구호·명단이 표시됩니다. 메인 화면의 분임 소개 버튼으로도 볼 수 있습니다.
6. 나중에 도착한 사람은 추가 참가자 칸에 이름을 넣고 **1명 추가**를 누릅니다. 인원이 가장 적은 분임 중 하나에 배치합니다.

자동 배정을 다시 누르면 현재 팀원 배정이 바뀝니다. 저장된 팀명과 구호는 유지합니다. 명단은 최대 300명이며, 초성 진행 중에는 분임 변경 버튼이 잠깁니다.

## 2. 초성게임 — 정답 버튼 한 번으로 진행

1. 진행요원 창에서 현재 진행 팀을 선택합니다. 팀을 선택하지 않으면 연습으로 기록됩니다.
2. 제시어 1~7 중 하나를 선택하면 카테고리가 먼저 크게 나옵니다.
3. **문제 시작 · 초시계 시작**을 누르면 초성과 초시계가 표시됩니다.
4. 팀이 맞히면 **정답 · 다음 문제**를 한 번 누릅니다. 정답을 **0.8초** 보여준 뒤 자동으로 다음 초성이 나옵니다. 전환 중 중복 클릭은 막았습니다.
5. 마지막 문제의 **마지막 정답 · 종료**를 누르는 시점에 기록이 멈춥니다. 정답을 보여준 뒤 완료 화면으로 넘어갑니다.

정답 공개에 쓰이는 0.8초는 소요시간에서 제외합니다. 문제를 푸는 시간만 누적하며, 이전·패스·임의 문제 선택 기능은 제공하지 않습니다. 다음 문제 전환은 직원용 화면이 처리하므로 직원용 창을 열어둔 상태에서 진행하세요.
완료 기록은 진행요원 창에 빠른 순서로 모입니다. 이 기록으로 점수나 최종 우승팀을 자동 결정하지 않습니다. 중단한 회차와 팀 미선택 연습은 완료 기록 표에 저장하지 않습니다.

## 3. 일심동체 — 제시어와 웹캠 함께 보기

1. USB 웹캠을 **직원용 화면을 띄우는 PC**에 연결합니다. 기존 Windows 카메라 앱과 웹캠을 쓰는 화상회의 앱은 닫습니다.
2. 일심동체에서 키워드 1~7 중 하나를 고릅니다. 왼쪽에 제시어·카운트, 오른쪽에 카메라 공간이 나옵니다.
3. **직원용 화면 오른쪽의 카메라 켜기**를 누르고, 브라우저가 요청하는 카메라 사용을 허용합니다. 진행요원 창에서는 카메라를 중복 실행하지 않습니다.
4. 다른 카메라가 연결되면 위 선택 메뉴에서 USB 웹캠을 고릅니다. 거꾸로 나오면 **180° 회전**, 좌우를 바꾸려면 **좌우 반전**을 누릅니다.
5. 진행요원 창의 **3초 카운트 시작 → 참가자 동작 확인 → 다음**으로 진행합니다. 같은 묶음의 다음 문제에서도 영상은 이어집니다.
6. 3문제를 끝내거나 다른 게임으로 나가면 카메라 연결이 꺼집니다. 다음 묶음에서 다시 켜주세요.

영상은 브라우저 화면에 실시간 표시하며 마이크·녹화·사진 저장·서버 전송 기능은 사용하지 않습니다. 카메라는 직접 켜기 버튼을 눌러야 시작합니다. Streamlit의 HTTPS 주소를 Chrome/Edge에서 열어 사용하세요.
권한 거부·장치 없음·다른 앱이 사용 중인 경우에는 카메라 자리 아래에 안내가 표시됩니다. 사이트 설정에서 카메라를 허용하고 다시 켜주세요.

기존 21문제는 다음과 같이 유지됩니다.

| 묶음 | 1번 | 2번 | 3번 |
|---|---|---|---|
| 키워드 1 | 군인 | 싸이 | 인사 |
| 키워드 2 | 야호 | bad(배드) | 힙합 |
| 키워드 3 | 스키점프 | 샤워 | 으르렁 |
| 키워드 4 | 스트레칭 | 셀카포즈 | 발레 |
| 키워드 5 | 운전 | 음악감상 | 사격 |
| 키워드 6 | 오토바이 | 생일 | 감기 |
| 키워드 7 | 커피 | 배구 | 애교 |

## 4. 최종 우승팀 발표

1. 점수는 종이 등으로 수기 집계합니다.
2. 진행요원 창의 **02 · 최종 우승팀 발표**를 펼칩니다.
3. 최종 우승 분임을 선택하고 **최종 우승 발표**를 누릅니다.
4. 직원용 화면에 우승팀명·구호와 축하 화면이 표시됩니다. 분임 선택만으로는 발표되지 않습니다.

## 기존 게임과 음악

- 음악퀴즈: 등록된 7개 영상 버튼으로 재생하며 모두 0초부터 시작합니다. 자동 재생이 되지 않으면 영상의 ▶를 누르세요. 외부 재생 제한이 있으면 유튜브에서 열기를 사용합니다.
- 명대사: 사진을 보고 맞힌 뒤 정답을 공개합니다. 23개 장면을 유지했습니다.
- 그림 이어그리기: 4명이 각각 기본 5초씩 그립니다. 4번 주자 뒤 종료 벨과 함께 자동으로 멈춥니다. 일시정지 후 이어가기는 같은 주자·남은 시간을 유지합니다.
- BGM: 진행요원 창에서 서커스/겨울 음악을 선택해 재생합니다. 음악퀴즈에 들어가면 BGM은 자동 일시정지되며, 이후 진행요원이 재개합니다.
- 메인 화면의 슈퍼마리오 모션과 화면 크기에 맞추는 구성은 유지했습니다.

## 화면 분리와 백업

메인 화면의 진행요원 창 열기를 누르고 **Windows + P → 확장**을 선택하세요. 직원용 창은 빔프로젝터, 진행요원 창은 노트북에 둡니다. 같은 PC·같은 브라우저의 일반 창에서 사용하세요.
진행 설정의 **백업 다운로드 / 백업 불러오기**로 분임 명단·팀명·구호·영상 링크·문제 수정·초성 완료 기록을 저장하고 복원합니다.
이전 백업의 팀명·문제·영상 링크는 유지하고, 점수 및 보너스 안무 설정은 더 이상 사용하지 않습니다. 이전 설정에 8팀이 있으면 앞의 7팀만 사용합니다.

## 확인 범위

수정판 14: 모의 웹캠으로 그림 게임 진입 시 표시·수동 연결·주자 전환/일시정지 시 영상 유지·4명 종료 뒤 영상 유지·다음 문제에서도 유지·게임 이동 시 연결 종료를 검사했습니다. 진행요원 창에서 중복 실행되지 않는지도 검사했습니다.

자동 검사: 5개 게임 순서, 보너스·점수판·지정 문구 제거, 1~300명 균등 배정과 중복 입력 처리, 추가 인원 배정, 팀명·구호 저장과 복원, 수동 우승 발표를 확인했습니다.
초성 정답 공개→자동 다음 문제·0.8초 제외·마지막 클릭 시점 종료·중복 클릭 방지·진행요원/직원 상태 전달을 검사했습니다. 기존 음악 링크·명대사·일심동체 묶음·그림 4명 타이머 검사도 통과했습니다.
카메라는 모의 장치로 연결·장치 전환·회전·연결 해제·권한 오류·다른 게임으로 이동했을 때 종료 처리를 검사했습니다. 이 환경에서 실제 USB 웹캠과 배포 화면으로 최종 확인하지는 못했으므로 행사 전에 사용하는 PC에서 연결을 확인해주세요.
