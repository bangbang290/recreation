# 레트로 워크숍 수정판 20 — 이름만 올려 7분임 자동 배정

## 적용 방법

ZIP을 풀고 **app.py, index.html, requirements.txt, README.md** 네 파일을 기존 GitHub 저장소에 덮어쓰세요. Streamlit 실행 파일은 app.py입니다.
적용이 끝나면 기존 직원용 화면과 진행요원 창을 모두 닫고 다시 여세요. 이전 버전 창을 함께 열어두지 마세요.

## 수정판 20: 이름만 올려 7분임 자동 배정

1. 관리자 첫 항목 **01 · 7분임 편성 / 팀명 / 구호**에서 **① 이름 입력 양식 받기**를 누릅니다.
2. 엑셀의 **참가자명단** 시트 **이름** 열에 한 줄에 한 명씩 적습니다. 분임 번호·팀명·구호는 입력하지 않습니다.
3. **② 이름 엑셀 올리기**로 파일을 선택하면 **즉시 7분임에 무작위로 배정·저장**됩니다. 별도 적용 버튼 없이 배정 결과가 표시됩니다.
4. 배정이 끝나면 **팀명·구호 입력 / 분임별 확인**을 열고 팀명·구호를 적은 뒤 저장합니다.

- 분임별 인원 차이는 최대 1명입니다. 이름 순서와 분임 순서를 모두 무작위로 섞어서 배정합니다.
- **다시 무작위 배정**으로 현재 명단을 다시 섞을 수 있습니다. **직전 배정 되돌리기**는 현재 관리자 창에서 마지막 배정을 한 번 되돌립니다. 이후 팀명·구호·명단을 수정하거나 창을 다시 열면 되돌리기가 제한됩니다.
- 새 파일을 올리면 기존 명단 전체를 새로 배정합니다. 이미 저장한 팀명·구호는 유지됩니다. 적용된 명단은 연결된 직원 화면·분임 소개·게임별 팀 선택에 반영됩니다.
- 이름은 30자 이내, 최대 300명, 파일은 .xlsx 형식으로 5MB까지입니다. 빈 줄은 건너뜁니다. 동명이인은 이름 뒤에 부서 등을 붙여 구분하세요.
- 중복 이름·수식·잘못된 파일을 발견하면 현재 명단을 바꾸지 않고 오류를 안내합니다. 게임 타이머가 진행 중일 때도 배정하지 않습니다.
- 이전 두 시트 양식을 올려도 참가자명단의 이름 열만 읽고 모두 무작위로 배정합니다. 이전 분임 번호·팀명·구호 칸은 읽지 않습니다.
- 양식은 index.html에 포함되어 있습니다. 배포용 네 파일만 GitHub에 덮어쓰면 됩니다. 엑셀 읽기는 현재 브라우저 안에서 처리하며 새 외부 라이브러리는 필요하지 않습니다.

## 수정판 18: 팩맨 네온 오락실

- 전체 배경과 TV 테두리를 검정·네이비 바탕의 파란 네온으로 변경했습니다. 바깥 Streamlit 화면과 진행요원 창도 같은 색상으로 맞췄습니다.
- 첫 화면에 파란 미로, 노란 점, 입을 움직이는 팩맨과 뒤따라오는 유령을 넣었습니다. 기존 ‘모션 끄기’ 버튼으로 움직임을 멈출 수 있습니다.
- 5개 게임팩은 핑크·노랑·초록·하늘·보라 네온 버튼으로 구분합니다. 게임 중에는 미로와 캐릭터를 숨겨 문제·사진·영상이 선명하게 보입니다.
- 초성·음악·일심동체 선택 화면, 분임 소개, 우승팀 발표, 카메라 조작부도 어두운 배경과 밝은 글자로 변경했습니다. 그림 타이머는 하늘색 → 주황색 → 진한 분홍색으로 다급해집니다.
- 게임 순서·문제·유튜브 링크·7분임 정보·백업 방식은 이전 버전과 같습니다. 새 효과음이나 BGM은 추가하지 않았습니다.

## 수정판 17: 음악퀴즈 1980년대 추가

음악퀴즈 → **1초 듣고 맞히기 → 1980년대**를 누르면 새 영상이 TV에 표시됩니다. 1980년대 버튼은 1990년대 앞에 배치했습니다.

- 영상: https://www.youtube.com/watch?v=oteHAZM1Um8
- 이전 요청대로 링크의 99초 지정은 적용하지 않고 **0초부터** 재생합니다.
- 음악퀴즈는 총 **8개 카테고리**입니다. 1초 듣기 4개(1980·1990·2000·2010년대), 가사 듣기 2개, OST 2개입니다.
- 진행요원 창의 카테고리 선택과 영상 링크 수정에도 1980년대 항목을 추가했습니다.
- 이전 저장 설정·백업은 새 링크만 추가하며, 기존에 수정한 다른 영상 주소나 팀 정보는 유지합니다. 이후 새 링크를 수정하거나 비워 저장한 경우에도 그 설정을 유지합니다.

## 수정판 16: 일심동체 7개 카테고리 × 5문제

추가한 14개 단어를 각 카테고리에 2개씩 배치했습니다. 기존 카테고리의 3문제는 그대로 두고 뒤에 2문제를 추가했습니다. 총 35개 단어를 중복 없이 한 번씩 사용합니다.
선택 화면·진행률·완료 버튼·진행요원 목록 모두 5문제 기준으로 바뀝니다. 다섯 번째 문제까지 진행한 뒤 **5문제 완료 · 키워드 선택**을 누르면 선택 화면으로 돌아갑니다. 예시 ‘하트’는 본 문제 수에 포함하지 않습니다.
이전 저장 설정과 백업은 자동으로 새 문제 구성에 맞춰 확장됩니다. 팀명·구호·명단·영상 링크·기존 제시어 수정은 유지합니다. 기존의 3문제 완료 표시는 새 5문제 진행에 맞춰 처음 한 번 초기화합니다.

## 수정판 15: 그림 카메라 확대 / 일심동체 카메라 제거

- 그림 이어그리기는 제목·제시어·타이머·카메라 조작 버튼을 왼쪽으로 모았습니다. 오른쪽 카메라는 제목이나 조작 막대에 높이를 빼앗기지 않고 TV 화면의 위아래를 모두 사용합니다.
- 그림 게임에서는 옆 장식 다이얼도 숨겨 영상 공간을 넓혔습니다. 영상은 원본 비율을 유지하며 잘리지 않습니다.
- ‘카메라를 껐습니다’, 정상 연결 등 평소 상태 문구는 표시하지 않습니다. 권한 거부·장치 없음 등 해결이 필요한 오류만 안내합니다.
- 일심동체에서는 카메라 공간과 연결 기능을 제거했습니다. 제시어·3초 카운트로 진행합니다.

### 그림 카메라 사용

1. USB 웹캠을 직원용 화면을 띄우는 PC에 연결하고 Windows 카메라 앱을 닫습니다.
2. 그림 이어그리기를 선택한 뒤 **왼쪽 카메라 켜기**를 누르고 권한을 허용합니다. 종이가 잘 보이도록 웹캠을 맞추세요.
3. 왼쪽에서 카메라 장치 선택·180° 회전·좌우 반전을 조절할 수 있습니다.
4. 주자 전환·일시정지·다음 그림 문제로 이동해도 영상은 이어집니다. 4번 주자 뒤에도 완성된 그림을 볼 수 있도록 카메라는 유지됩니다.
5. **끄기** 또는 다른 게임으로 이동하면 웹캠 연결이 종료됩니다. 카메라 끄기는 그리기 타이머를 중단하지 않습니다.

카메라는 직원용 화면에서 직접 켜야 합니다. 마이크·녹화·영상 서버 전송 기능은 사용하지 않습니다.

### 더 다급해진 그림 타이머

- 기본 **4명 × 각 5초**입니다. 4번 주자가 끝나면 자동 종료됩니다.
- 숫자가 박동하고 남은 시간 막대가 줄어듭니다. 마지막 3초는 주황색, 마지막 1초는 빨간색으로 바뀌며 박동도 빨라집니다.
- 5·4초에는 초당 한 번, 3초에는 두 번, 2초에는 세 번, 1초에는 네 번 빠르게 소리가 납니다. 사람 목소리는 사용하지 않습니다.
- 주자 변경과 마지막 종료 시 벨이 울립니다. 일시정지·수동 주자 전환·정지 시 예약된 효과음도 취소합니다.
- 직원용 화면에서 **효과음 켜기**를 누르면 소리를 들을 수 있습니다. 효과음을 꺼도 타이머와 화면 변화는 계속됩니다.
- 기기의 움직임 줄이기 설정에서는 숫자 박동을 생략하고 색과 남은 시간으로 표시합니다.

## 수정판 13에서 반영한 내용

- 게임 순서: **초성 → 음악퀴즈 → 일심동체 → 명대사 → 그림 이어그리기**.
- 그림 이어그리기 대기 화면의 첫 주자·마지막 주자 안내 문구를 삭제했습니다. 4명 × 기본 5초, 사람 목소리 없이 효과음과 종료 벨을 사용합니다.
- 보너스 안무를 메뉴와 진행 기능에서 제거했습니다.
- 이름 명단을 7개 분임에 자동 배정하고, 팀명·구호·명단을 수정·저장할 수 있습니다.
- 점수 입력·계산·점수판을 제거했습니다. 수기 집계한 최종 우승팀을 진행요원이 직접 선택해 발표합니다.
- 초성은 정답 버튼 한 번으로 정답 공개 후 자동으로 다음 문제로 넘어갑니다.
- 카메라는 현재 그림 이어그리기에서만 사용합니다.

## 1. 분임 배정과 팀명·구호

1. 진행요원 창 상단에서 **01 · 7분임 편성 / 팀명 / 구호**를 펼칩니다.
2. 참가자 이름을 한 줄에 한 명씩 붙여넣습니다. 쉼표로 구분해도 됩니다. 동명이인은 부서 등을 붙여 구분하세요.
3. **7분임 자동 배정**을 누릅니다. 명단을 무작위로 섞어 분임별 인원 차이가 최대 1명이 되도록 배정합니다.
4. 분임별 팀명과 구호를 입력하고 **팀명·구호·명단 저장**을 누릅니다. 아래 팀원 명단을 직접 옮겨 적어 조정을 할 수도 있습니다.
5. **직원 화면에 분임 소개**를 누르면 TV 화면에 7개 분임의 팀명·구호·명단이 표시됩니다. 메인 화면의 분임 소개 버튼으로도 볼 수 있습니다.
6. 나중에 도착한 사람은 추가 참가자 칸에 이름을 넣고 **1명 추가**를 누릅니다. 인원이 가장 적은 분임 중 하나에 배치합니다.

자동 배정을 다시 누르면 현재 팀원 배정이 바뀝니다. 저장된 팀명과 구호는 유지합니다. 명단은 최대 300명이며, 초성 진행 중에는 분임 변경 버튼이 잠깁니다.

## 2. 초성게임 — 정답 버튼 한 번으로 진행

1. 진행요원 창에서 현재 진행 팀을 선택합니다. 팀을 선택하지 않으면 연습으로 기록됩니다.
2. 제시어 1~7 중 하나를 선택하면 카테고리가 먼저 크게 나옵니다.
3. **문제 시작 · 초시계 시작**을 누르면 초성과 초시계가 표시됩니다.
4. 팀이 맞히면 **정답 · 다음 문제**를 한 번 누릅니다. 정답을 **0.8초** 보여준 뒤 자동으로 다음 초성이 나옵니다. 전환 중 중복 클릭은 막았습니다.
5. 마지막 문제의 **마지막 정답 · 종료**를 누르는 시점에 기록이 멈춥니다. 정답을 보여준 뒤 완료 화면으로 넘어갑니다.

정답 공개에 쓰이는 0.8초는 소요시간에서 제외합니다. 문제를 푸는 시간만 누적하며, 이전·패스·임의 문제 선택 기능은 제공하지 않습니다. 다음 문제 전환은 직원용 화면이 처리하므로 직원용 창을 열어둔 상태에서 진행하세요.
완료 기록은 진행요원 창에 빠른 순서로 모입니다. 이 기록으로 점수나 최종 우승팀을 자동 결정하지 않습니다. 중단한 회차와 팀 미선택 연습은 완료 기록 표에 저장하지 않습니다.

## 3. 일심동체 — 카메라 없이 진행

1. 키워드 1~7 중 하나를 고릅니다. 각 묶음에 5문제가 있습니다.
2. 제시어를 확인하고 **3초 카운트 시작**을 누릅니다.
3. 참가자가 동시에 동작하면 진행요원이 일치 여부를 확인하고 다음 문제로 넘어갑니다.
4. 5문제를 마치면 키워드 선택 화면으로 돌아갑니다. 카메라는 표시되지 않으며 실행되지 않습니다.

총 35문제의 카테고리 구성은 다음과 같습니다.

| 묶음 | 1번 | 2번 | 3번 | 4번 | 5번 |
|---|---|---|---|---|---|
| 키워드 1 | 군인 | 싸이 | 인사 | 볼링 | 원숭이 |
| 키워드 2 | 야호 | bad(배드) | 힙합 | 스파이더맨 | 고양이 |
| 키워드 3 | 스키점프 | 샤워 | 으르렁 | 태권도 | 야구 |
| 키워드 4 | 스트레칭 | 셀카포즈 | 발레 | 낚시 | 농구 |
| 키워드 5 | 운전 | 음악감상 | 사격 | 매트릭스 | 닭 |
| 키워드 6 | 오토바이 | 생일 | 감기 | 해리포터 | 향수 |
| 키워드 7 | 커피 | 배구 | 애교 | 안경 | 전화 |

## 4. 최종 우승팀 발표

1. 점수는 종이 등으로 수기 집계합니다.
2. 진행요원 창의 **02 · 최종 우승팀 발표**를 펼칩니다.
3. 최종 우승 분임을 선택하고 **최종 우승 발표**를 누릅니다.
4. 직원용 화면에 우승팀명·구호와 축하 화면이 표시됩니다. 분임 선택만으로는 발표되지 않습니다.

## 기존 게임과 음악

- 음악퀴즈: 등록된 8개 영상 버튼으로 재생하며 모두 0초부터 시작합니다. 자동 재생이 되지 않으면 영상의 ▶를 누르세요. 외부 재생 제한이 있으면 유튜브에서 열기를 사용합니다.
- 명대사: 사진을 보고 맞힌 뒤 정답을 공개합니다. 23개 장면을 유지했습니다.
