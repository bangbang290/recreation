# 레트로 워크숍 수정판 12 — 초성 초시계와 그림 4명 진행

## 깃허브 적용
압축을 풀고 app.py, index.html, requirements.txt, README.md 네 파일을 기존 저장소에 덮어쓰세요. Streamlit 진입 파일은 app.py입니다.
적용 후 기존 직원용 화면과 진행요원 창을 모두 닫고 앱을 다시 여세요.

## 초성게임 — 패스 없이 시간 경쟁
1. 진행요원 창에서 현재 진행 팀을 선택합니다. 팀을 선택하지 않으면 연습으로 진행하며 순위용 시간은 저장하지 않습니다.
2. 직원용 화면에서 제시어 1~7 중 하나를 고릅니다. 카테고리가 먼저 크게 표시되고 초시계는 00:00.00에서 대기합니다.
3. ‘문제 시작 · 초시계 시작’을 누르면 첫 초성과 함께 시간이 흐릅니다. 문제를 바꿔도 시간이 계속 누적됩니다.
4. 팀이 맞히면 진행요원이 ‘정답 확인’ → ‘맞힘 · 다음 문제’를 누릅니다. 정답 확인 전에는 다음으로 넘어갈 수 없습니다. 이전·임의 문제 선택·순서 섞기도 막아 패스 없이 진행합니다.
5. 마지막 문제를 맞힌 뒤 ‘마지막 정답 · 기록 종료’를 누르면 초시계가 멈춥니다. 완주한 팀의 이름·카테고리·문제 수·소요시간이 진행요원 창에 자동 저장됩니다.
6. 다음 팀을 선택하고 다시 제시어를 고릅니다. ‘처음부터 다시 준비’는 현재 진행을 취소하고 준비 화면으로 돌아가며, 완료된 기록은 유지합니다.

직원용 화면과 진행요원 창에 경과시간을 표시합니다. 완료 기록 표는 진행요원 창에만 있으며 소요시간이 짧은 순서로 정렬됩니다. 재도전 기록도 별도로 남으므로 여러 번 진행했다면 해당 회차를 보고 비교하세요. 기록은 백업 JSON에 포함됩니다. 중간에 게임을 나가거나 중단한 회차는 완료 기록에 넣지 않습니다.

## 그림 이어그리기 — 4명
1. 그리는 사람 4명을 순서대로 세웁니다. 첫 주자에게만 제시어를 보여준 뒤 ‘4명 그리기 시작’을 누릅니다.
2. 기본 설정은 1번 5초 → 2번 5초 → 3번 5초 → 4번 5초입니다. 화면에 현재 주자와 남은 초를 표시합니다.
3. 시계 째깍 소리로 카운트하고 주자가 바뀔 때 벨이 울립니다. 4번 주자의 시간이 끝나면 종료 벨과 ‘4명 완료’가 표시되며 자동으로 멈춥니다. 5번 주자는 시작되지 않습니다.
4. 완성된 그림으로 정답을 맞힙니다. 다시 진행하려면 ‘4명 다시 시작’, 새 문제는 ‘다음’을 누릅니다.

일시정지 후 이어가기는 현재 주자와 남은 시간을 유지합니다. 자동 카운트 정지는 진행을 중단하며, 다시 시작하면 1번부터 시작합니다. 한 사람당 시간은 진행요원 창에서 변경할 수 있지만 그리는 인원은 4명으로 고정했습니다. 사람 목소리는 사용하지 않습니다.

## 일심동체 진행 (수정판 11)
1. 메인 화면에서 일심동체를 누르면 ‘키워드 1~7’ 선택 화면이 나옵니다. 선택 전에는 실제 문제를 보여주지 않습니다.
2. 팀에서 키워드 하나를 고릅니다. 직원용 버튼 또는 진행요원 창의 ‘일심동체 키워드 선택’에서 선택할 수 있습니다.
3. 해당 묶음의 첫 문제가 표시됩니다. 3초 카운트 시작 → 참가자 동작 확인 → 다음 순서로 진행합니다.
4. 세 번째 문제까지 끝낸 뒤 ‘3문제 완료 · 키워드 선택’을 누르면 선택 화면으로 돌아오고, 해당 묶음에 완료 표시가 붙습니다. 다음 묶음의 문제가 이어서 공개되지 않습니다.
5. 다음 팀은 다른 키워드를 선택합니다. 완료된 묶음도 다시 선택할 수 있습니다. ‘완료 표시 초기화’는 진행 표시만 지우고 점수를 유지합니다.

기존 문제 순서대로 3개씩 묶었습니다. 화면에는 한 문제씩 보여주며, 진행요원 창에서는 선택한 묶음의 3문제를 함께 확인할 수 있습니다.

| 묶음 | 첫 번째 | 두 번째 | 세 번째 |
|---|---|---|---|
| 키워드 1 | 군인 | 싸이 | 인사 |
| 키워드 2 | 야호 | bad(배드) | 힙합 |
| 키워드 3 | 스키점프 | 샤워 | 으르렁 |
| 키워드 4 | 스트레칭 | 셀카포즈 | 발레 |
| 키워드 5 | 운전 | 음악감상 | 사격 |
| 키워드 6 | 오토바이 | 생일 | 감기 |
| 키워드 7 | 커피 | 배구 | 애교 |

- 예시 하트는 별도 연습 문제이며 팀당 3문제에 포함되지 않습니다.
- ‘이 3문제 순서 섞기’와 ‘이 3문제 원래 순서’는 선택한 묶음 안에서만 동작합니다. 다른 묶음의 구성은 바뀌지 않습니다.
- 키워드 완료 표시와 편집한 제시어는 백업 JSON에 포함됩니다. 이전 백업도 불러올 수 있습니다.
- 앱을 새로 열면 일심동체는 키워드 선택 화면부터 표시합니다. 저장된 점수·완료 표시·수정 문구는 유지합니다.

## 음악퀴즈 진행
1. 메인 화면에서 음악퀴즈를 누릅니다.
2. 원하는 카테고리 버튼을 누르면 TV 안에 연결된 영상이 바로 표시되고 자동 재생을 요청합니다. 진행요원 창의 카테고리 선택 메뉴로도 고를 수 있습니다.
3. 브라우저가 자동 재생을 막으면 직원용 TV 영상 안의 ▶를 한 번 누릅니다. 재생·일시정지·전체화면은 영상 자체 버튼으로 조작합니다.
4. 카테고리 선택 버튼으로 목록에 돌아갑니다. 중간에 보너스 안무를 진행하고 음악퀴즈로 돌아올 수 있습니다.

영상 링크 7개가 미리 등록되어 있으므로 추가 입력 없이 사용할 수 있습니다. 모두 0초부터 시작합니다. 처음 전달된 링크의 23초·47초 지정은 제거했고, 음악퀴즈에 나중에 입력하는 링크의 시간 지정도 적용하지 않습니다.

- 가사 퀴즈의 버튼 이름은 최신 요청대로 2000년대·2010년대로 바꿨습니다.
- 이전 수정판 9의 빈 링크 설정이 브라우저에 남아 있어도 이번 7개 주소를 한 번 자동 반영합니다. 팀 이름·점수는 유지합니다. 이후 진행요원이 변경하거나 삭제한 링크는 다시 덮어쓰지 않습니다.
- 진행요원 창의 카테고리별 영상 링크에서 주소를 수정하고 영상 링크 저장을 눌러 교체할 수 있습니다.
- 점수 변경·팀 선택만으로 재생 중인 영상을 다시 불러오지 않습니다. 카테고리 선택 화면·보너스·다른 게임으로 이동하면 TV 안의 이전 영상이 제거되어 재생이 멈춥니다.
- 외부 재생이 제한된 영상은 유튜브에서 열기를 이용하세요. 따로 연 유튜브 창은 직접 멈춰야 합니다.

## 화면과 점수
1. 메인 화면 맨 위의 진행요원 창 열기를 누릅니다. 새 탭은 별도 창으로 끌어내도 됩니다.
2. Windows + P → 확장. 직원용 화면은 빔프로젝터, 진행요원 창은 노트북에 둡니다.
3. 팀 점수는 진행요원 창에만 표시됩니다. 설정·점수·영상 링크·초성게임 완료 시간은 백업 JSON으로 저장할 수 있습니다.
같은 PC의 같은 Chrome/Edge 일반 창에서 사용하세요. 화면 분리 기능이며 별도 로그인이나 접근권한 구분은 아닙니다.

## 유튜브 BGM
진행요원 창에서 서커스 또는 겨울 선택 → 플레이어 연결 → 재생을 누릅니다. 음량과 반복을 조절할 수 있습니다.
음악퀴즈 및 보너스 안무에 들어가면 BGM이 자동 일시정지됩니다. 다른 게임으로 돌아간 뒤 재생을 눌러 재개합니다.
BGM은 진행요원 창에서만 재생합니다. 진행요원 창을 닫으면 BGM도 종료됩니다.
기본 링크: 서커스 https://www.youtube.com/watch?v=UyPNvJsr92g / 겨울 https://www.youtube.com/watch?v=-u13DgqNCt8

## 나머지 게임과 모션
- 명대사 퀴즈: 장면 먼저 → 정답 공개. 23개 장면.
- 카테고리 초성게임: 제시어 1~7 → 카테고리 공개 → 초시계 시작 → 패스 없이 완주. 본 문제 70개 + 예비 12개.
- 일심동체: 7개 키워드 × 3문제 = 21개 제시어. 예시 하트는 별도입니다.
- 그림 이어그리기: 본 문제 14개 + 예비 4개. 종이와 펜으로 4명이 기본 5초씩 진행하고 4번 주자 뒤 자동 종료됩니다. 사람 목소리 없이 째깍 효과음과 종료 벨을 사용합니다. 직원용 화면에서 효과음 켜기를 한 번 누르세요. 4번 주자가 끝나면 자동으로 멈춥니다.
- 첫 화면: 슈퍼마리오 달리기·블록·코인·굼바·파이프·깃발 모션. 모션 끄기/켜기로 조절합니다. 게임에 들어가면 숨겨집니다.

## 확인 범위
초성 초시계의 문제 간 연속 측정·마지막 정답 종료·중복 기록 방지·패스 방지·팀 미선택 연습 처리·이전 백업 호환을 확인했습니다. 그림 4명×5초의 자동 전환·종료 벨·자동 정지·5번 주자 방지·일시정지와 재시작도 검사했습니다.
일심동체 7개 묶음의 21문제 중복·누락 여부, 선택 전 문제 숨김, 묶음당 3문제 종료, 완료 표시, 진행요원 선택, 예시·순서 섞기, 이전 백업과 점수 보존 검사를 통과했습니다. 이번 UI의 실제 배포 화면 검증은 완료하지 못했습니다.
7개 영상 ID·버튼 연결, 모든 영상의 0초 시작 주소 생성, 이전 빈 링크의 자동 반영, 이후 수정 내용과 점수 보존, 영상·보너스 전환, 진행요원 중복 재생 방지와 기존 게임 검사를 통과했습니다.
이 환경에서는 유튜브 영상을 직접 불러올 수 없어 실제 재생과 영상별 외부 재생 허용 여부는 확인하지 못했습니다. 배포된 Streamlit에서 사용해주세요. 광고·자동 재생·외부 재생 제한의 영향을 받을 수 있습니다. 로컬 index.html 더블클릭은 게임 화면 미리보기용입니다.
